# Liquid Class Bench

**Demo, still in development.** A simulated P200 air-displacement pipette for exploring liquid-class settings (rates, delays, blowout).

**Live page:** https://sl148.github.io/liquid-class-bench/

- **Simulate:** animated transfer, channel pressure, and where volume is lost.
- **Optimize:** speed vs accuracy search and a rate map.
- **Model:** equations and loss mechanisms.
- **Guide** (top right): labels and short notes on each view.

Coefficients come from textbook scaling laws, not a calibrated instrument. Use the trends, not the numbers.
